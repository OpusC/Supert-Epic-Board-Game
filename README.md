# Super Epic Board Game

1. Clone the repository or extract the project ZIP.
2. Download the standard **Godot 4.7** editor. This project was tested with 4.7.1. [Godot downloads](https://godotengine.org/download/archive/)
3. In Godot’s Project Manager, click **Import** and select `project.godot`.

**Play.** Press **F5** to start the training encounter.

**Edit cards.** Click **Cards** in the top workspace bar, select a card, edit its fields or use **+ Add effect**, then click **Save**. If the game is running, stop it with **F8** and press **F5** again to try the saved changes.
